# Tasking ドキュメント

Tasking は、同期イベントから開始した非構造化タスクを、キャンセル後も実終了まで所有し、終了を待つためのライブラリである。
標準 Swift の寿命管理が処理に合う場合は、その仕組みを優先する。

[TaskingPrototype](../Examples/TaskingPrototype/Sources/TaskingPrototype/PrototypeApp.swift) は、
保存、標準 SwiftUI による検索、ダウンロード、画面を越える同期、通常の async による課金情報の取得を実装する。
ライブラリを使う例と標準機能で足りる例を、同じアプリで比較できる。
