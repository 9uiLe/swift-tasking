# ADR-0004: 寿命を実行の選択ラベルとして扱う

## 前提

処理を画面・シーン・アプリのどこまで継続させるかは、アプリケーションの所有構成で決まる。
画面の構成方法によって、キャンセルを要求すべきイベントも異なる。

## 決定

`ActionLifetime` は Store 内の実行を照会・一括キャンセルするためのラベルとする。
`.screenBound`・`.sceneBound`・`.appBound` と、任意の文字列を使える。
Store の配置とライフサイクルイベントへの接続は利用側が行う。

Store は解放時に所有中のすべてのタスクへキャンセルを要求する。
明確な終了時点が必要な場合は、利用側からキャンセルや終了待ち API を呼ぶ。

## 理由と制約

呼び出し箇所で意図した寿命を表しながら、ライブラリを特定の画面管理方式に依存させずに済む。
同じラベルを使う共有 Store の一括キャンセルは、すべての該当する実行に及ぶ。

ラベルは Store の寿命を延ばさず、OS のバックグラウンド実行権限も与えない。
アプリ全体で継続する処理にはアプリ側の所有者を置く。
配置と参照関係は [寿命と所有構成](../lifetimes.md) に示す。
