# ADR-0004: lifetime を選択用のラベルとして扱う

## 前提

画面・シーン・アプリのどこまで処理を継続したいかは、利用側の所有構成で決まる。
SwiftUI、UIKit、独自の画面構成では、キャンセルを要求するイベントも異なる。

## 決定

`ActionLifetime` は論理的な寿命のラベルとする。組み込み値は `.screenBound`、
`.sceneBound`、`.appBound` とし、任意の文字列でも定義できる。
Store はラベルによる照会と `cancel(lifetime:)` を提供する。
ライフサイクルイベントとの接続は利用側が行う。

Store の `deinit` は所有中の全 task にキャンセルを要求する。
これは強制終了ではなく、operation の協調が必要な安全網である。

## 理由と制約

ラベルにより、処理をどの寿命で所有したいかをレビューできる。
ライブラリに View や Scene の監視を持たせず、所有構成とイベント選択をアプリに委ねる。

`.appBound` を指定しても Store の寿命は延びない。画面が所有する Store では、
Store 解放時に task がキャンセルされる。アプリ全体で継続したい処理はアプリ側に Store を置く。
OS による background suspend やプロセス終了に対する継続保証はない。

共有 Store 内で同じラベルを使うと、一括キャンセルはすべての該当 run に及ぶ。
所有構成とラベルの範囲を合わせる。[ライフタイムと所有構成](../lifetimes.md) に例を示す。
