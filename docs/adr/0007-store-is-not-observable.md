# ADR-0007: 追跡と UI の観測可能な状態を分ける

## 前提

重複判定の対象であることと、読み込み表示を続けることは別の判断である。
キャンセルしたタスクは追跡から外れても実行を続ける場合があり、UI には直前の結果やエラーも必要になる。

## 決定

Store と Runner は `Observable` / `ObservableObject` にしない。
`isRunning` と `runningCount` は、呼び出し時点の追跡状態を返す同期照会とする。
UI は ViewModel の観測可能な状態を表示する。

## 理由と制約

アプリケーションは開始・成功・失敗・キャンセルの表示を、追跡規則から独立して定義できる。
Tasking 自体も Observation や Combine に依存せずに済む。

SwiftUI の `body` で追跡を照会しても、その変化だけでは再描画されない。
ViewModel がすべての終了経路で状態を確定させ、実行が重なる場合は結果と後処理を世代で保護する。
実装例は [利用レシピ](../recipes.md) を参照する。
