# ADR-0012: Store の追跡と所有を独立させる

## 前提

Store はキャンセルした実行を重複判定から外しながら、その処理の実終了を確認できる必要がある。
追跡と所有は終了する時点が異なる。

## 決定

追跡索引に ActionID・ActionRunID・寿命ラベルを保持し、所有台帳にタスクのハンドルと所有識別子を保持する。
開始時は両方へ登録し、キャンセル時は追跡だけを解除する。終了時は該当する実行を両方から除く。

`awaitCompletion(of:)` は、ActionID と ActionRunID が一致する所有中の実行を待つ。
終了済みか、この Store が所有しない実行なら直ちに戻る。
`waitForIdle()` は所有するすべてのタスクを待ち、待機中に開始した実行も含める。

## 理由と制約

重複判定と終了待ちがそれぞれ必要な情報を参照でき、追跡解除後もハンドルを移動せずに保持できる。
`isRunning == false` と、終了待ちが中断している状態は両立する。

待機側のキャンセルは対象の実行に伝播せず、待機も中断しない。
自己待機は Debug でアサーション、Release では継承した所有文脈の除外で扱う。
受付停止は [ADR-0014](0014-store-terminal-close.md) に定める。
処理が終了しない場合は待機も完了せず、業務結果の正しさは ViewModel やサービスの状態で別に検証する。
