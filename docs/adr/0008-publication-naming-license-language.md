# ADR-0008: 名称・ライセンス・文書言語を定める

## 前提

ライブラリは、明示的な task 所有の設計を読む・利用する・自分のコードへ取り込むための
リファレンス実装として公開する。利用時の名称と、判断を記録する文書の役割を統一する。

## 決定

- リポジトリと Swift package の名称は `swift-tasking` とする。
- product / import 名は、UI 向けを `Tasking`、非 UI の所有を `TaskingCore` とする。
- MIT ライセンスで配布する。
- README と公開 API の documentation comment は英語で書く。
- `docs/` の設計解説と ADR は日本語で書く。
- 用語の意味は [用語集](../glossary.md) に揃える。

## 理由と制約

package 名と import 名の対応を固定し、利用者が依存を選べるようにする。
英語の公開 API 説明は Xcode の Quick Help から参照でき、詳しい設計判断は日本語で記録する。
言語ごとの説明が異なる契約にならないよう、API の変更では両方を確認する。

実装方法はコード、観測できる振る舞いはテスト、継続して必要な判断の根拠は ADR に置く。
個々の変更に固有の動機はコミットメッセージに記録する。
