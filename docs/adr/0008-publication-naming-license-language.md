# ADR-0008: 名称・ライセンス・文書言語を定める

## 前提

ライブラリは、アプリケーションへの導入と、タスク所有の設計を学ぶために公開する。
利用者が参照する名前と、保守者が説明や判断を記録する言語を統一する。

## 決定

| 対象 | 方針 |
|---|---|
| リポジトリ・Swift package | `swift-tasking` |
| product・import | UI 向けは `Tasking`、非 UI の所有は `TaskingCore` |
| ライセンス | MIT。ライセンス本文は原文を保持する |
| 文書・API コメント・実装コメント・コミット・PR | 日本語を第一言語とする |
| README・貢献ガイド・セキュリティポリシー | 日本語を正本とし、対応する `.en.md` を同時に保守する |
| 設計資料・ADR・変更履歴・運用手順 | 日本語で管理する |
| 識別子・プロトコルのフィールド名・コマンド・固定された CI 名 | 既存の表記を使う |

用語は [用語集](../glossary.md) に揃える。
対応する日本語版と英語版は、同じ API・例・動作要件・導入バージョンを説明する。

## 理由と制約

設計・API・運用の説明を日本語に揃えることで、文書間の読み替えを抑えられる。
英語版は利用・貢献・脆弱性報告の入口に用意し、翻訳の保守範囲を明確にする。
リリースツールは両 README の依存バージョンを更新・検証する。

文書は目的・前提・契約を単独で理解できる形にする。
実装方法はコード、観測可能な振る舞いはテスト、継続して必要な根拠は ADR に置く。
個々の変更の動機と経緯はコミットメッセージに記録する。
