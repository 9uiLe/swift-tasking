# ADR-0008: 名称・ライセンス・文書言語を定める

## 前提

ライブラリは、明示的な task 所有の設計を読む・利用する・自分のコードへ取り込むための
リファレンス実装として公開する。利用時の名称と、判断を記録する文書の役割を統一する。

## 決定

- リポジトリと Swift package の名称は `swift-tasking` とする。
- product / import 名は、UI 向けを `Tasking`、非 UI の所有を `TaskingCore` とする。
- MIT ライセンスで配布する。
- 日本語をリポジトリの第一言語とし、文書・公開 API コメント・実装コメント・コミットメッセージ・PR に使う。
- README・コントリビューションガイド・セキュリティポリシーは日本語を正本とし、`.en.md` の英語版を提供する。
- 設計解説・ADR・変更履歴・運用手順は日本語で管理する。
- コードの識別子、プロトコルのフィールド名、コマンド名、固定された CI チェック名は既存の表記を保つ。
- MIT ライセンスは原文を保持する。
- 用語の意味は [用語集](../glossary.md) に揃える。

## 理由と制約

package 名と import 名の対応を固定し、利用者が依存を選べるようにする。
設計・API・運用の説明を日本語に揃え、読者が文書間で言語を切り替える負担を抑える。
公開 API の日本語の説明は Xcode の Quick Help からも参照できる。
英語話者にも利用・貢献・脆弱性報告の入口を提供しつつ、翻訳の保守範囲は限定する。
対応する日本語版と英語版は同時に更新し、同じ API・例・動作要件を説明する。
リリースツールは両 README の依存バージョンを更新・検証し、導入手順の不一致を防ぐ。

実装方法はコード、観測できる振る舞いはテスト、継続して必要な判断の根拠は ADR に置く。
個々の変更に固有の動機はコミットメッセージに記録する。
