# ADR-0008: 公開名称・ライセンス・ドキュメント言語

- ステータス: 確定(2026-07-03 グリリングで作者決定)。実装変更は未実施
- 日付: 2026-07-03

## 文脈

公開にあたり 3 つの運用事項が未決だった:
(1) パッケージ名 `TaskRunner`・プロダクト名 `Tasking`・リポジトリ名 `task-runner` の
三重名称、(2) LICENSE ファイルの不在(公開ブロッカー)、(3) doc コメント日本語・
README 英語・docs/ 日本語という言語の混在。
公開ゴールは「設計思想の提示・コピー歓迎」(positioning.md §6)。

## 決定

1. **名称は `swift-tasking` に統一する。**
   リポジトリ名・Package.swift の name を `swift-tasking`、プロダクト名と
   import 名は `Tasking` のまま。swift-async-algorithms 等と同じ
   コミュニティ慣習に従い、検索性を確保する。
2. **ライセンスは MIT。**
   コピーして取り込む障壁が最も低く、「コピー歓迎」のゴールと整合する。
3. **言語は二層構造を明文化する。**
   - API 接点(README・doc コメント)= **英語**。Xcode quick help /
     Swift Package Index で全利用者に見えるため。
   - 設計思想(docs/・ADR)= **日本語**。思想のニュアンス伝達を優先。
   - 現状日本語である doc コメントの英訳は移行作業として残る。

## 代償

- リポジトリリネームで既存参照(クローン URL・リンク)が切れる。公開前の今が
  最小コストのタイミングであるため受け入れる(GitHub はリダイレクトを張る)。
- doc コメント英訳の作業コストと、翻訳による意味の劣化リスク。
  用語は glossary.md の語彙に固定して緩和する。
- 設計 docs が日本語のため、非日本語圏には思想が届きにくい。ゴール(§6)上、
  採用数を追わないため受け入れる。

## 未解決の問い

- リネームと英訳の実施時期(実装変更を伴うため本セッション外。
  Codex 等への委譲プロンプトを作成済み)。
